# Portfólio — Denis Goes

Portfólio estático em HTML, CSS e JavaScript.

## Publicar no Render

O arquivo `render.yaml` configura um site estático. Para publicar:

1. Envie este repositório para o GitHub.
2. No Render, escolha **New > Blueprint** e conecte o repositório.
3. Revise o serviço `denis-goes-portfolio` e confirme a criação.

O Render executa o comando de build definido no Blueprint e publica os arquivos
gerados em `public/`. Cada novo push para a branch conectada inicia uma nova
publicação.

## Formulário de contato

O formulário envia as mensagens pelo FormSubmit. Na primeira submissão,
confirme o endereço `d.goesdev@gmail.com` pela mensagem de ativação enviada pelo
serviço. Depois dessa confirmação, os envios seguem diretamente para a caixa de
entrada, sem abrir o aplicativo de email do visitante.

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta do projeto com um servidor local.
